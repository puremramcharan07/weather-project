# 🌤️ Weather App

A simple Python-based Weather Application that displays real-time weather information for any city using the OpenWeather API.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Current temperature
- 🌡️ Feels-like temperature
- 💧 Humidity
- 💨 Wind speed
- ☁️ Weather condition
- 🖥️ User-friendly Tkinter GUI
- ⚠️ Error handling for invalid cities and connection problems

## 🛠️ Technologies Used

- Python
- Tkinter
- Requests
- OpenWeather API
